SWEEP = LFO (Sine / Triangle / Saw / Square). ENVELOPE follows level, TOUCH kicks on each note, TALK adds a second formant. PEDAL follows CC4 / CC11 / CC1 / the expression jack. The automatic modes need no pedal.
